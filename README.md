# How to run this project

- Clone the repository

  `git clone "THIS REPOSITORY"`
  
- Open Live Server in your Web Browser
- Play with the application all you like!

## Important Note

- The visualizer is built with p5.js
- There may be some limitation in the 2D and 3D rendering support since p5.js can not render from 3D to 2D
